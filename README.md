# generative-ai-requirements-traceability
AI-assisted requirements engineering system for analyzing requirement quality, generating test cases, and automatically creating trace links between requirements and tests.

## Steps to Run

1. Open Docker Desktop
2. Open terminal in root folder and run .\start-dev.ps1

### Tools

* Frontend : React.js
* Backend : Python with FastAPI
* DB : PostgreSQL 
* Vector DB : Weaviate
* LLM : OpenAI
